About

I am an Information Systems student from Surabaya, Indonesia. I love building software that is simple, fast, and easy to use. My passion for programming started with exploring Linux systems and learning how software interacts with hardware.

Today, I focus on two main areas: system script automation and web development. For system scripts, I write POSIX shell modules for Android (like SkiaVK to improve UI rendering and DexForge to optimize app compilation based on device RAM).

On the web side, I build clean web applications like Bayu Bagus Bakery using HTML5, CSS3, and Vanilla JavaScript. I prefer avoiding heavy frameworks whenever possible so that websites load instantly and run smoothly.

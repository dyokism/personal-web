About

I am an Information Systems student based in Surabaya, Indonesia, specializing in web application development. I focus on building clean, fast, and accessible web apps using Vanilla JavaScript, HTML5, and CSS3. One of my favorite achievements was taking the initiative to design and deploy a complete B2B ordering portal for my father's bakery in Nganjuk, turning a real business need into a working production app.

My approach to web development is shaped by a strong background in Linux and system scripting. I got into tech by tweaking Android custom ROMs, moving from Linux Mint to Vanilla Arch, and writing POSIX shell root modules like SkiaVK and DexForge.

Understanding how software interacts with underlying hardware helps me write cleaner web code. I prefer avoiding heavy frameworks when simple, native web technologies can load faster, run smoother, and deliver a better user experience.

About

I am an Information Systems student based in Surabaya, Indonesia, working across systems tooling and native web interfaces. I build web applications with zero-framework Vanilla JavaScript, HTML, and CSS, and write system-level automation for Linux and Android environments.

On the systems side, I maintain root-level tooling like SkiaVK (Vulkan HWUI pipeline redirection) and DexForge (automated Dalvik/ART compilation daemon). On the web side, I build fast, accessible applications with clean semantic markup and zero runtime bundle overhead.

I avoid heavy frameworks when native browser APIs solve the problem with zero dependencies, lower memory footprints, and faster load times.
